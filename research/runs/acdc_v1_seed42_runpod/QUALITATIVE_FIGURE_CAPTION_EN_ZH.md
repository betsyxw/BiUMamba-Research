# ACDC Qualitative Figure Caption

## English

Qualitative comparison on the isolated ACDC test set using the validation-selected seed-42 checkpoints. From left to right: input cardiac MRI, ground truth, E1 prediction using original four-direction SS2D, and E2_modify_2 prediction using the channel-grouped bidirectional scan. Red, green, and blue indicate the right ventricle, myocardium, and left ventricle, respectively. Typical, difficult, E2 failure, and thin-myocardium cases were selected by pre-recorded objective rules; all methods use the same patient, cardiac phase, slice, preprocessing, and color map. Difficult and E2-failure criteria selected the same volume in this test run and are shown separately for transparency.

## 中文

隔离ACDC测试集上的定性对比，使用仅由验证集选择的seed-42 checkpoint。从左到右依次为：输入心脏MRI、Ground Truth、采用原始四方向SS2D的E1预测，以及采用通道分组双向扫描的E2_modify_2预测。红色、绿色和蓝色分别表示右心室、心肌和左心室。典型、困难、E2失败和薄心肌病例按照预先记录的客观规则选择；所有方法使用相同患者、心动阶段、slice、预处理和颜色方案。本次测试中“困难病例”和“E2失败病例”规则选择了同一体积，为保证透明性仍分别展示。

# E4 Version 1 — Full 300-Epoch Synapse Run

**Research Author and Repository Maintainer:** xuwen

**Affiliation:** Japan Advanced Institute of Science and Technology (JAIST)

This folder archives the lightweight, shareable records for E4 Version 1. It includes the final E4 metrics, the six-experiment overall comparison, the eight-organ comparison, the archive report, and the structured manifest.

The run completed successfully, but it produced a Red decision outcome: Mean Dice `70.9089%` and Mean HD95 `35.3190`. E2_modify_2 remains the current reference model.

The favorable E4 50-epoch screening trajectory did not reproduce in the full run. This mismatch must be audited before another full E4 experiment is launched.

Datasets, patient images, NIfTI predictions, checkpoints, pretrained weights, binary archives, credentials, and keys are intentionally excluded.

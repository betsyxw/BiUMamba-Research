# Result figures

**Updated: 20260912**

This directory contains GitHub-safe aggregate result figures for BiUMamba.

## Contents

- `statistics/paired_difference_forest_plot.png`: patient-level paired effects and bootstrap confidence intervals.
- `statistics/paired_difference_distributions.png`: paired metric-difference distributions.
- `statistics/busi_size_shape_contrast_analysis.png`: aggregate BUSI subgroup analysis.
- `tables/`: rendered versions of selected final result tables.
- `paper_evidence_20260912/`: final E1-versus-BiUMamba method diagram,
  Dice-memory and NSD-memory Pareto figures, and the patient-level forest plot
  in PNG and PDF formats.

## Data-release boundary

Qualitative panels containing source CT, MRI, or ultrasound pixels are intentionally excluded from this public repository. They remain in the private verified results package for paper preparation and authorized review.

This restriction is required because dataset access does not automatically grant public redistribution rights. In particular, the official ACDC license prohibits sharing or distributing the dataset or modified versions containing its data. The original BUSI release does not provide an explicit redistribution license, and Synapse access conditions must be checked at the dataset level.

Only aggregate plots and tables that do not expose source medical-image pixels are stored here.

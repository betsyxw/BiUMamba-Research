## Authorship convention for this repository

Future research-specific source files and reports should include:

```text

```

Future commits should use `xuwen` as the Git author name when made through Git,
or include `Author: xuwen` in the commit description when the GitHub web editor
is used. A verified GitHub email should be configured before relying on Git
commit metadata for formal attribution.

VMamba work. Their original code, copyright, citations, and license notices
remain attributed to the upstream authors. The `xuwen` attribution applies to
the research-specific modifications and records in this repository; it does
not replace or claim authorship of upstream source code.
